# OpenFigure 半身复刻：已公开资产 vs 缺失资产矩阵 v0.1

## 1. 使用方式

| 字段 | 说明 |
|---|---|
| 已公开 | 当前仓库中已能看到或已验证存在 |
| 未公开 / 不明确 | 当前仓库中未发现或无法确定 |
| 阻断等级 | 对半身复刻推进的影响程度 |
| 行动建议 | 下一步如何处理 |

## 3. 阻断等级定义

| 等级 | 含义 |
|---|---|
| 低 | 不影响当前研究推进 |
| 中 | 影响后续细化，但暂不阻断 |
| 高 | 会阻断打印前准备 |
| 很高 | 会阻断复刻立项后的实际开工 |

---

## 4. 当前最关键的 8 个缺失项

| 优先级 | 缺失项 | 原因 |
|---:|---|---|
| 1 | 装配图 | 没有就无法稳定装配 |
| 2 | 电机型号清单 | 没有就无法落地关节 |
| 3 | 轴承 / 标准件清单 | 没有就无法形成机械闭环 |
| 4 | 电机与 STL 的安装关系 | 决定结构是否可实现 |
| 5 | 减速 / 传动方案 | 决定性能和装配逻辑 |
| 6 | bin 与硬件映射 | 连接机械、电气与控制 |
| 7 | 打印材料与参数建议 | 决定样件是否有效 |
| 8 | bring-up / 校准流程 | 决定后续真机是否可控 |
