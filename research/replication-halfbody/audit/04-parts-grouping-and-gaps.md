## 3. 从复刻角度的“已知 / 未知”分类

### 3.1 当前已知

| 类别 | 已知信息 | 价值 |
|---|---|---|
| 结构层级 | 清楚 | 可建立装配树 |
| 左右镜像 | 明显 | 可降低理解成本 |
| 关节顺序 | 清楚 | 可建立运动链认知 |
| 部分质量 / 惯量 | 已知 | 对估算结构复杂度有帮助 |
| 关节行程 | 已知 | 对设计约束有帮助 |
| 控制力矩范围 | 部分已知 | 可反推执行器等级 |

### 3.2 当前未知（机械）

| 未知项 | 严重度 | 影响 |
|---|---|---|
| 每个 STL 是否可直接打印 | 高 | 直接影响落地 |
| 是否需要分件二次装配 | 很高 | 影响打印与制造策略 |
| 是否有嵌件 / 金属加强件 | 很高 | 影响强度和设计可行性 |
| 轴承型号与数量 | 很高 | 无法装配转动副 |
| 联轴器 / 输出轴结构 | 很高 | 无法建立关节传动 |
| 电机安装位细节 | 很高 | 无法形成真实关节 |
| 螺丝规格与长度 | 很高 | 无法装配 |
| 是否有隐藏内部零件未公开 | 很高 | 可能导致 STL 仍不足以复刻 |
| 线缆走线空间 | 中高 | 影响真实可用性 |
| 打印材料建议 | 高 | 影响可靠性 |
| 打印方向 / 支撑策略 | 中高 | 影响成品质量 |

## 4. 复刻阻断项分层

### 4.1 一级阻断项（没有就无法开工）

| 阻断项 | 原因 |
|---|---|
| 电机 / 驱动 / 传动方案 | 决定关节核心可实现性 |
| 轴承 / 标准件清单 | 决定关节能否装起来 |
| 装配关系图 | 决定 STL 是否真能组合成实物 |
| 紧固件规格 | 决定结构是否能闭环 |

### 4.2 二级阻断项（能开工但高概率踩坑）

| 阻断项 | 原因 |
|---|---|
| 打印材料建议 | 强度与尺寸稳定性 |
| 打印方向 / 公差说明 | 装配质量 |
| 线缆走线 / 维护空间 | 后续可维护性 |
| 末端夹爪说明 | 影响半身完整度 |

---

## 5. 对当前打印策略的建议

| 建议 | 判断 |
|---|---|
| 现在就全量开打 21 个 STL | 不建议 |
| 先做结构理解和缺口追问 | 建议 |
| 后续抽样打印 1~2 个代表件 | 建议 |
| 优先抽样对象 | 腰部件、肩部件 |
| 原因 | 这两类最能暴露关节装配与强度问题 |

## 7. 本轮结论

| 问题 | 结论 |
|---|---|
| 当前半身机械资产是否有研究价值 | 很高 |
| 当前是否更适合“结构反向理解”而非直接制造 | 是 |
| 当前最需要作者补哪类信息 | 标准件、传动、电机、装配关系 |
| 用户下一步最该做什么 | 基于这份缺口表向作者定向提问 |
