# OpenFigure 半身复刻路线图 v0.1

## 1. 路线图目标

| 项目 | 内容 |
|---|---|
| 目标对象 | `Semi-Taks-T1` 半身机器人 |
| 用户目标 | 最终走向可复刻、可装配、可控制的半身实体 |
| 当前阶段 | 审计 / 规划阶段 |
| 原则 | 先半身、先机械、先闭环、后扩展 |

---

## 2. 总体阶段划分

| 阶段 | 名称 | 当前状态 | 完成标志 |
|---:|---|---|---|
| 0 | 仓库理解与环境验证 | 已完成基础部分 | MuJoCo / demo /资产结构看清 |
| 1 | 机械资产审计 | 进行中 | 明确已知 / 缺失 / 阻断项 |
| 2 | 复刻缺口确认 | 待推进 | 拿到作者 / 社区回复 |
| 3 | 打印前准备 | 未开始 | 确定材料、标准件、关键工艺 |
| 4 | 抽样打印与装配验证 | 未开始 | 至少验证 1~2 个关键关节件 |
| 5 | 半身结构成套制造 | 未开始 | 核心结构件可装配 |
| 6 | 电气 / 驱动 bring-up | 未开始 | 单关节通电可控 |
| 7 | 半身系统联调 | 未开始 | 双臂 / 腰 / 颈能稳定运行 |

---

## 3. 每阶段目标与任务

### 阶段 0：仓库理解与环境验证

| 项目 | 状态 |
|---|---|
| 拉取仓库 | 已完成 |
| fork 并建立研究目录 | 已完成 |
| MuJoCo 环境验证 | 已完成 |
| demo 运行验证 | 已完成 |
| 基础审计文件落盘 | 已完成 |

### 阶段 1：机械资产审计

| 任务 | 状态 | 说明 |
|---|---|---|
| STL 统计 | 已完成 | 21 个 STL |
| 关节链梳理 | 已完成 | 腰 + 双臂 + 颈 |
| 制造视角分组 | 已完成 | 已形成零件分组表 |
| 缺口识别 | 已完成初版 | 标准件 / 装配 / 电机等不足 |
| 抽样件优先级建议 | 已完成初版 | 腰部件、肩部件优先 |

### 阶段 2：复刻缺口确认

| 任务 | 优先级 | 说明 |
|---|---:|---|
| 向作者确认 STL 完整性 | P0 | 判断是否还有隐藏零件 |
| 向作者索取 BOM / 装配图信息 | P0 | 解决一级阻断项 |
| 明确电机 / 驱动映射 | P0 | 解决关节实现问题 |
| 明确是否存在金属加工件 | P1 | 判断打印边界 |
| 明确夹爪开放计划 | P2 | 影响末端完整性 |

### 阶段 3：打印前准备

| 任务 | 优先级 | 说明 |
|---|---:|---|
| 确认打印材料 | P0 | 结构强度前提 |
| 建立标准件采购表 | P0 | 装配前提 |
| 建立执行器候选表 | P0 | 关节闭环前提 |
| 选取抽样打印件 | P1 | 控制实验成本 |
| 规划打印策略 | P1 | 方向 / 支撑 / 公差 |

### 阶段 4：抽样打印与装配验证

| 任务 | 建议 | 原因 |
|---|---|---|
| 先打印腰部件 | 建议 | 载荷高、结构复杂、最能暴露问题 |
| 再打印肩部件 | 建议 | 电机 / 轴承 / 关节接口最关键 |
| 暂缓末端件全量打印 | 建议 | 末端细节与夹爪尚未清楚 |
| 记录装配问题 | 必须 | 为后续修正与提问提供依据 |

## 4. 关键决策点

| 决策点 | 触发条件 | 需要回答的问题 |
|---|---|---|
| 是否继续投入半身复刻 | 拿到作者回复后 | 资产是否足够闭环 |
| 是否开始批量打印 | 完成阶段 3 后 | 标准件与材料是否明确 |
| 是否进入电气阶段 | 机械样件可装配后 | 电机 / 驱动是否有明确方案 |
| 是否继续向整机扩展 | 半身闭环后 | 腿部与平衡控制是否成熟 |

---

## 5. 当前主要阻断项

| 阻断项 | 严重度 | 所属阶段 |
|---|---|---|
| BOM 缺失 | 很高 | 2 / 3 |
| 装配图缺失 | 很高 | 2 / 3 |
| 电机 / 驱动映射缺失 | 很高 | 2 / 3 |
| 标准件信息缺失 | 很高 | 2 / 3 |
| 打印材料建议缺失 | 高 | 3 |
| 夹爪资产不完整 | 中 | 5 / 7 |

## 7. 近期里程碑（建议版）
