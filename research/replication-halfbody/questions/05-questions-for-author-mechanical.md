# OpenFigure 面向作者的问题清单（机械复刻向）v0.1

## 使用原则

| 原则 | 说明 |
|---|---|
| 聚焦复刻 | 问题尽量服务“半身复刻” |
| 先机械后电气 | 避免一上来问太散 |
| 追阻断项 | 优先问会阻断开工的问题 |
| 减少空泛提问 | 用具体文件和部位提问 |

---

## A. 资产完整性问题

| 编号 | 问题 | 目的 |
|---:|---|---|
| A1 | `assets/Semi_Taks_T1/meshes` 中这 21 个 STL，是否已经覆盖半身结构件的全部打印件？ | 判断是否还有未公开零件 |
| A2 | 半身复刻是否还依赖未公开的内部支架、金属连接件或加强件？ | 判断 STL 是否足够 |
| A3 | 后续是否会发布原始 CAD / STEP 文件，而不只是 STL？ | 判断二次编辑可能性 |
| A4 | `waist_pitch_link.STL` 是否就是 torso 相关主结构件的最终制造版本？ | 澄清命名与制造边界 |

---

## B. 装配问题

| 编号 | 问题 | 目的 |
|---:|---|---|
| B1 | 半身是否有装配图、 exploded view 或装配顺序文档计划？ | 判断装配可执行性 |
| B2 | 腰部三轴（yaw / roll / pitch）的装配关系是否有示意图？ | 优先解决腰部核心难点 |
| B3 | 左右肩关节的电机、轴承、输出轴是如何固定到各自 STL 中的？ | 解决肩部复刻难点 |
| B4 | 腕部三轴的传动结构是直驱、减速器还是其他形式？ | 明确腕部方案 |
| B5 | 末端夹爪是否会开放机械结构？当前半身模型为何未包含独立夹爪链？ | 澄清末端完整性 |

---

## C. 标准件与制造问题

| 编号 | 问题 | 目的 |
|---:|---|---|
| C1 | 半身各关节对应的轴承型号、数量、安装方式是否会提供清单？ | 解决装配闭环 |
| C2 | 螺丝、铜柱、垫片、联轴器等标准件是否会提供 BOM？ | 解决采购闭环 |
| C3 | 官方推荐的打印材料是什么（PLA / PETG / ABS / 尼龙 / CF）？ | 解决强度问题 |
| C4 | 是否会提供关键件的打印方向、层高、填充率建议？ | 解决打印可行性 |
| C5 | 是否存在必须 CNC / 金属加工的零件，而非全部可打印？ | 识别制造边界 |

---

## D. 执行器 / 传动相关问题

| 编号 | 问题 | 目的 |
|---:|---|---|
| D1 | 半身各关节对应使用的电机型号分别是什么？ | 建执行器映射表 |
| D2 | `firmware/` 中不同 `.bin` 文件分别对应哪些电机 / 驱动型号？ | 连接机械与电气 |
| D3 | 腰、肩、肘、腕、颈分别采用了什么等级的驱动方案？ | 理解力矩分配 |
| D4 | 是否会发布半身电机 / 驱动 / 控制板 BOM？ | 判断复刻时间点 |

---

## E. 复刻路线问题

| 编号 | 问题 | 目的 |
|---:|---|---|
| E1 | 如果目标是个人先复刻 `Semi-Taks-T1`，官方推荐先从哪个子模块开始？ | 获取最小可行路径 |
| E2 | 半身复刻目前最大的已知难点是什么：结构、装配、驱动、电气还是控制？ | 明确风险排序 |
| E3 | 近期是否计划优先开放半身 BOM / 装配资料，而不是全身资料？ | 判断跟进节奏 |
| E4 | 对个人开发者而言，当前最现实的复刻里程碑是什么？ | 对齐预期 |

## 最值得优先发出的 5 个问题

| 优先级 | 问题 |
|---:|---|
| 1 | 这 21 个 STL 是否已经覆盖半身全部可打印结构件？ |
| 2 | 半身是否还依赖未公开的金属件 / 内部支架 / 标准件？ |
| 3 | 是否会发布半身装配图、BOM、轴承与紧固件清单？ |
| 4 | 半身各关节对应的电机 / 驱动型号是什么？ |
| 5 | 如果个人要先复刻 `Semi-Taks-T1`，官方建议从哪个子模块起步？ |
