# OpenFigure 独立复刻线：硬件准备调研 v0.1

## 1. 研究前提

| 项目 | 内容 |
|---|---|
| 假设 | 不等待官方继续开放完整资料，自己单开半身复刻线 |
| 目标对象 | `Semi-Taks-T1` 半身机器人 |
| 当前已知 | 有 mesh / URDF / MuJoCo / demo / 部分固件 bin / 作者回复 |
| 当前未知 | 大量机械装配、电机、驱动、标准件、电气细节 |
| 重要前提 | 用户自有 3D 打印机 |
| 当前结论性质 | 假设性调研，不代表立即采购或开工 |

---

## 2. 如果自己单开一条线，核心变化是什么

| 官方等待路线 | 自主并行路线 |
|---|---|
| 等官方补装配资料 / BOM / 视频 | 自己先做逆向、选型、试错 |
| 跟随官方硬件方案 | 可能需要自己定义部分硬件栈 |
| 风险更低但更慢 | 速度可能更快，但试错成本更高 |
| 装配细节由官方兜底 | 你需要自己补装配、标准件和驱动方案 |

---

## 3. 需要准备的硬件类别（总表）

| 类别 | 是否必需 | 当前状态 | 备注 |
|---|---|---|---|
| 3D 打印设备 | 是 | 已有 | 当前优势项 |
| 打印材料 | 是 | 待选型 | 直接影响结构强度 |
| 标准紧固件 | 是 | 未准备 | 必须自己建规格体系 |
| 轴承 / 衬套 / 联轴件 | 是 | 未准备 | 当前未知较多 |
| 电机 / 执行器 | 是 | 未选型 | 最大硬件难点之一 |
| 电机驱动器 | 是 | 未选型 | 与电机强耦合 |
| 控制板 / 主控 | 是 | 未选型 | 需要自己定义架构 |
| 电源系统 | 是 | 未选型 | 台架供电可先于电池 |
| 线束 / 接插件 | 是 | 未准备 | 装配与维护关键 |
| IMU / 传感器 | 部分必需 | 未明确 | 至少要满足半身 bring-up |
| 夹爪 / 手部末端 | 可后置 | 未明确 | 不一定要在第一阶段解决 |
| 测试工具 | 是 | 需补齐 | 不能只靠打印机 |
| 工装夹具 | 高度建议 | 未准备 | 装配复杂度高时很重要 |

## 4. 最应该优先准备的硬件，不是“买电机”，而是这些底层能力

### 4.1 制造与装配能力

| 物项 | 优先级 | 原因 |
|---|---:|---|
| 打印材料若干（不同强度等级） | P0 | 后续需要抽样测试 |
| 卡尺 / 千分尺 | P0 | 无法只靠 STL 盲打 |
| 螺纹规 / 螺丝样本盒 | P1 | 反推标准件规格 |
| 热熔铜柱 / 热压工具 | P1 | 很多打印结构会依赖 |
| 台虎钳 / 小夹具 | P1 | 装配与定位很需要 |
| 轴承压装 / 简易工装 | P1 | 关节类结构基本离不开 |
| 万用表 | P0 | 后续电气必须 |
| 可调直流电源 | P0 | 比电池更适合 bring-up |

### 4.2 研发试验能力

| 物项 | 优先级 | 原因 |
|---|---:|---|
| 一台常驻 Linux / Ubuntu 机器 | P0 | 控制与调试主机 |
| 可视化仿真环境 | P0 | 已具备基础，可继续沿用 |
| 台架固定结构 | P1 | 半身初期建议固定测试 |
| 急停 / 断电开关 | P0 | 真机测试必须 |
| 扭矩 / 温度 / 电流观测手段 | P1 | 控制风险 |

## 5. 真正最难的硬件部分：执行器与传动

这是如果不等官方时，最容易把项目难度抬高一个数量级的部分。

### 5.1 你需要自己补齐的执行器问题

| 问题 | 当前状态 | 难度 |
|---|---|---|
| 每个关节该用什么电机 | 未知 | 很高 |
| 电机峰值 / 连续扭矩要多少 | 只能参考仿真力矩 | 很高 |
| 是否要减速器 | 未知 | 很高 |
| 编码器方案 | 未知 | 高 |
| 驱动器协议 | 未知 | 高 |
| 固件是否可复用 | 不确定 | 高 |

### 5.2 从当前资产中能反推出什么

| 已知线索 | 价值 |
|---|---|
| MuJoCo actuator force 范围 | 可粗略推演关节等级 |
| `firmware/*.bin` 文件名中的 DM 型号 | 提示作者可能使用某类电机 / 驱动生态 |
| 半身关节链 | 可帮助拆成不同扭矩等级 |
| 作者说半身已验证较成熟 | 说明官方硬件方案大概率已有稳定版本 |

### 5.3 如果你真要单开线，执行器建议策略

| 策略 | 建议 |
|---|---|
| 不要一开始全关节一起定型 | 对 |
| 先做扭矩等级分层 | 对 |
| 先做腰 / 肩 / 肘 / 腕 / 颈 五类关节级别划分 | 对 |
| 优先做单关节测试台 | 强烈建议 |
| 在没搞清电机前先全量打印 | 不建议 |

## 6. 需要准备的硬件分层（建议版）

### 层 1：最低研究准备（现在就能做）

| 物项 | 用途 | 备注 |
|---|---|---|
| 打印材料若干 | 抽样打印 | PLA/PETG 只够摸形态，未必够最终件 |
| 卡尺 / 基础装配工具 | 尺寸确认 | 必备 |
| 研究用工作台 | 摆放零件 | 必备 |
| Ubuntu / 仿真环境 | 软件侧持续推进 | 已具备基础 |

### 层 2：进入“自主机械试错”前必须具备

| 物项 | 用途 | 备注 |
|---|---|---|
| 标准件样品库 | 反推装配规格 | 很重要 |
| 轴承样品库 | 对照关节尺寸 | 很重要 |
| 热熔铜柱 / 工装 | 打印件装配 | 常见刚需 |
| 小型压装/固定夹具 | 轴承与结构装配 | 很重要 |
| 台架固定方案 | 防止半身测试时倾倒 | 建议提前 |

### 层 3：进入“自主电气 bring-up”前必须具备

| 物项 | 用途 | 备注 |
|---|---|---|
| 可调电源 | 安全上电 | 优先于电池 |
| 万用表 | 基础调试 | 必备 |
| 示波器（可选但强烈建议） | 通信/驱动排障 | 有帮助 |
| 急停开关 | 安全 | 必备 |
| 线束材料与压接工具 | 电气系统搭建 | 必备 |
| 控制主机 / 控制板 | 跑控制栈 | 必备 |

## 8. 对“硬件准备”的现实判断

| 问题 | 当前判断 |
|---|---|
| 你现在就适合买一堆电机吗？ | 不适合 |
| 你现在适合补齐基础工装与测试能力吗？ | 适合 |
| 现在最值得先准备的硬件是什么？ | 测量 / 装配 / 安全上电 / 台架测试能力 |
| 最大风险点在哪里？ | 自主定义执行器与传动方案 |
| 当前最稳妥的自主路线是什么？ | 机械先行、单关节验证、再扩到半身 |

---

## 9. 建议的独立复刻线硬件准备顺序

| 顺序 | 准备项 | 原因 |
|---:|---|---|
| 1 | 补齐测量与装配工具 | 这是所有硬件工作的底座 |
| 2 | 建立标准件 / 轴承样品库 | 为逆向装配做准备 |
| 3 | 建台架与安全上电条件 | 避免后面测试过于危险 |
| 4 | 做执行器分级与候选件研究 | 再进入电机层 |
| 5 | 做单关节样件验证 | 控制试错成本 |
| 6 | 再决定是否扩大到半身系统 | 避免过早重投入 |

---

## 10. 本轮结论

| 结论 | 判断 |
|---|---|
| 如果不等官方，能不能单开一条线？ | 能，但门槛显著上升 |
| 最大新增工作量在哪？ | 执行器、传动、装配闭环 |
| 当前最值得准备的硬件，不是直接采购全套机器人件，而是底层研发能力 | 是 |
| 当前最推荐的策略 | 先准备测量 / 装配 / 安全上电 / 台架能力，再做执行器研究 |
