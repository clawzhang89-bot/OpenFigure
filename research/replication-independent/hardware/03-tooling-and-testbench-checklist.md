# OpenFigure 独立复刻线：基础工装与测试设备清单 v0.1

## 1. 文档目标

| 项目 | 内容 |
|---|---|
| 目标 | 明确如果未来独立开线，最先需要补齐哪些基础工装和测试设备 |
| 范围 | 半身复刻前期：机械逆向、抽样打印、单关节测试、基础 bring-up |
| 结论性质 | 假设性准备清单，不代表立即采购 |
| 核心原则 | 先补研发底座，再碰高风险执行器采购 |

---

## 2. 为什么先做这份清单

| 常见误区 | 更合理做法 |
|---|---|
| 先急着买电机 | 先补测量、装配、安全测试能力 |
| 先想整机 | 先想单关节和子系统 |
| 只靠 3D 打印机 | 打印机只是制造入口，不是完整研发平台 |
| 先拼材料 | 先建立可重复测试条件 |

---

## 3. 工装与设备总表

| 类别 | 必要性 | 当前意义 |
|---|---|---|
| 测量工具 | 必需 | 没有它几乎无法逆向与复刻 |
| 机械装配工具 | 必需 | 没有它无法稳定装结构件 |
| 打印后处理工具 | 高度建议 | 影响实际装配质量 |
| 台架固定与夹具 | 必需 | 单关节测试基本离不开 |
| 电气基础工具 | 必需 | 后续 bring-up 基础 |
| 安全与断电工具 | 必需 | 真机/半真机测试必须 |
| 数据采集与观察工具 | 高度建议 | 帮助排障与迭代 |

---

## 4. 第一层：测量工具（优先级最高）

| 物项 | 优先级 | 用途 | 备注 |
|---|---:|---|---|
| 游标卡尺 | P0 | 测量 STL 对应实物尺寸、标准件孔位 | 必备 |
| 深度尺 | P1 | 孔深、嵌件深度测量 | 很常用 |
| 角度尺 / 数显角度仪 | P1 | 关节安装与对位 | 有帮助 |
| 螺纹样规 / 螺丝样本 | P1 | 反推螺纹规格 | 对逆向很实用 |
| 精密钢尺 | P1 | 大尺寸粗测 | 基础工具 |

### 这一层的意义

| 没有这些会怎样 | 结果 |
|---|---|
| 看 STL 猜尺寸 | 高概率出错 |
| 打印完再碰运气装 | 会反复返工 |
| 无法识别标准件体系 | 后续采购混乱 |

---

## 5. 第二层：机械装配工具

| 物项 | 优先级 | 用途 | 备注 |
|---|---:|---|---|
| 六角扳手全套 | P0 | 结构装配 | 必备 |
| 扭力起子 / 扭力扳手（小规格） | P1 | 避免打印件过拧 | 很有价值 |
| 台虎钳 | P0 | 固定零件 | 必备 |
| 小型夹具 / 快速夹 | P1 | 临时固定与对位 | 强烈建议 |
| 轴承压装辅助块 / 套筒 | P1 | 压装轴承 | 强烈建议 |
| 热熔铜柱安装工具 | P1 | 打印件嵌件装配 | 高频需求 |
| 橡胶锤 / 小冲子 | P2 | 轻敲定位 | 视情况 |

### 这一层的意义

| 关键作用 | 说明 |
|---|---|
| 降低打印件装配损伤 | 打印件比金属件更怕粗暴装配 |
| 提升重复性 | 多次拆装不至于失控 |
| 支持单关节试验 | 单轴测试时很实用 |

---

## 6. 第三层：打印后处理工具

| 物项 | 优先级 | 用途 | 备注 |
|---|---:|---|---|
| 去毛刺工具 | P1 | 清理孔口和边缘 | 常用 |
| 锉刀 / 砂纸 | P1 | 微调配合面 | 常用 |
| 小型手钻 / 钻头组 | P1 | 修孔和配合 | 很实用 |
| 丝锥（视情况） | P2 | 特定孔位处理 | 看设计需要 |
| 热风枪 | P2 | 局部热修整 | 视材料而定 |

### 这一层的意义

| 作用 | 说明 |
|---|---|
| 把“能打印出来”变成“能装上去” | 很多问题出在后处理 |
| 提升试制效率 | 比重复重打更高效 |

---

## 7. 第四层：台架与固定系统

这是如果未来要单开线，最值得尽早想清楚的一层。

| 物项 | 优先级 | 用途 | 备注 |
|---|---:|---|---|
| 铝型材 / 木质测试底座 | P0 | 做单关节或半身测试台 | 强烈建议 |
| 通用安装板 | P1 | 固定电机 / 关节件 | 很实用 |
| 可调整支架 | P1 | 变化测试姿态 | 建议 |
| 扎带、理线夹、绑带 | P1 | 线束管理 | 必需 |
| 防倾倒配重 / 固定夹 | P0 | 保证测试安全 | 必需 |

### 这一层的意义

| 没有台架会怎样 | 结果 |
|---|---|
| 单关节测试时到处乱晃 | 数据和安全都失控 |
| 半身结构没有固定基座 | 早期测试风险很高 |
| 每次装一个临时支撑 | 浪费大量时间 |

---

## 8. 第五层：电气基础工具

| 物项 | 优先级 | 用途 | 备注 |
|---|---:|---|---|
| 万用表 | P0 | 电压、电流、导通检查 | 必备 |
| 可调直流电源 | P0 | 安全上电 | 比电池更适合前期 |
| 电烙铁 / 焊接工具 | P1 | 线束和临时接口制作 | 视方案而定 |
| 压接钳 / 端子工具 | P1 | 线束制作 | 很重要 |
| 示波器 | P2 | 通信与驱动问题排查 | 有条件建议 |
| USB-CAN / USB-串口等接口工具 | P1 | 后续调驱动和控制板 | 很可能需要 |

### 这一层的意义

| 作用 | 说明 |
|---|---|
| 安全 bring-up | 不必一上来就接复杂供电 |
| 快速排障 | 很多问题不是软件而是供电或接线 |
| 支持原型阶段反复改线 | 非常关键 |

---

## 9. 第六层：安全设备

| 物项 | 优先级 | 用途 | 备注 |
|---|---:|---|---|
| 急停开关 | P0 | 立刻断电 | 必备 |
| 总电源开关 | P0 | 统一控制 | 必备 |
| 保险 / 限流措施 | P1 | 降低误接风险 | 建议 |
| 防护眼镜 | P1 | 装配 / 上电保护 | 建议 |
| 耐高温垫 / 防火区域 | P1 | 电气测试安全 | 建议 |

### 这一层的意义

| 作用 | 说明 |
|---|---|
| 降低损坏与伤人风险 | 一旦动起来就是机电系统，不是普通模型 |
| 让测试可持续 | 没安全措施会严重拖慢推进 |

---

## 10. 按阶段建议的准备顺序

| 顺序 | 先准备什么 | 原因 |
|---:|---|---|
| 1 | 测量工具 + 基本装配工具 | 这是最底层能力 |
| 2 | 台架固定系统 | 为单关节和抽样件测试做准备 |
| 3 | 电气基础工具 + 可调电源 | 为后续 bring-up 打底 |
| 4 | 安全系统 | 进入机电测试前必须有 |
| 5 | 更高级的数据采集工具 | 等进入调试阶段再加 |

---

## 11. 哪些东西现在就值得有，哪些不必急

### 11.1 现在就值得准备

| 物项 | 判断 |
|---|---|
| 游标卡尺 | 值得 |
| 基本六角与装配工具 | 值得 |
| 台虎钳 / 小夹具 | 值得 |
| 可调直流电源 | 值得 |
| 万用表 | 值得 |
| 铝型材 / 测试台思路 | 值得 |

### 11.2 现在不必急着准备

| 物项 | 判断 | 原因 |
|---|---|---|
| 大批量执行器 | 不急 | 选型信息仍不足 |
| 全套电池系统 | 不急 | 前期更适合台架供电 |
| 高端测控设备 | 不急 | 还没到那一步 |
| 整机级装配工装 | 不急 | 目前目标还是半身与单关节 |

---

## 12. 本轮结论

| 结论 | 判断 |
|---|---|
| 独立复刻线最先该补的是研发底座，而不是整机件采购 | 是 |
| 工装和测试台会直接影响你后面推进速度 | 是 |
| 可调电源、万用表、测量工具、装配夹具属于最早应准备的一层 | 是 |
| 在执行器未明确前，先把测试条件搭起来是更稳的做法 | 是 |
